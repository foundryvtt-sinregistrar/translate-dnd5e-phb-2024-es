# D&D 5e PHB 2024 Spanish Translation

Spanish translation of the official D&D 5e Player's Handbook 2024 for Foundry VTT, using Babele.

## Requirements
- Foundry VTT v13+
- dnd5e system 5.2.x
- Babele

## Install
1. In Foundry, go to Add-on Modules → Install Module → Install from Manifest URL
2. Use:
   https://raw.githubusercontent.com/foundryvtt-sinregistrar/translate-dnd5e-phb-2024-es/main/module.json

## Release flow
- version is managed in module.json
- tags like v1.13.2 trigger GitHub release automation
- the generated zip is uploaded as a GitHub release asset
